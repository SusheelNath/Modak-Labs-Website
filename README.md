# Modak Labs — The world, made intelligent.

Portfolio website for Modak Labs, a spatial computing lab based in Abu Dhabi, UAE.

## Structure

Single-page application (`index.html`) with five sections:

- **Home** — Hero, trust strip (delivered-for clients & credentials), capability cards
- **Case Studies** — Six completed projects across government, infrastructure, healthcare, cultural heritage, urban planning, and immersive XR
- **Capabilities** — Service offerings and technology stack
- **About** — Lab background and team
- **Contact** — Project inquiry form

## Features

- Fully self-contained single HTML file (no external dependencies at runtime)
- Multilingual support: English, Arabic (RTL), Chinese, French
- Responsive across desktop, tablet, and mobile
- Hand-tracking HCI demo (MediaPipe)
- Dark theme with spatial computing aesthetic

## Deployment

Static site — serve `index.html` from any static host.
